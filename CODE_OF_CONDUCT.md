# Code of conduct

This project is small and run by one maintainer. These rules apply in issues, pull requests and anywhere else the project is discussed.

## Expected

- Be kind and specific. Criticise the work, not the person.
- Assume the other person is acting in good faith, and say so when you disagree.
- Keep to the topic of the issue or pull request.

## Not accepted

- Harassment, insults, slurs, threats, or sexual content.
- Posting anyone's private information, such as an address, a phone number or private messages.
- Adding real user data, secrets or private details about any person to a fixture, a log or a field report.

## Reporting

- On the comment, issue or pull request, open the "..." menu and choose **Report content**.
- Or open an issue titled "Conduct report", without details. The maintainer will reply and arrange a private way to talk.

## What happens

The maintainer may edit or delete comments, close issues or pull requests, and block anyone who breaks these rules. A first, minor problem usually gets a warning. Harassment or threats lead to a block.
